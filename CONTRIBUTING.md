# Contributing

Thanks for helping. Good places to start are in `ISSUES.md`.

1. Open an issue for anything larger than a typo, so we can agree the shape first.
2. Run `npm test` and `node src/cli.mjs data/maps` before sending a pull request.
3. Data changes need a reason a teacher could check (a syllabus code, a source, a short explanation of why one skill comes before another).
4. By contributing you agree that code is under Apache-2.0 and data is under CC BY 4.0.

Be kind and specific in reviews. Teachers, curriculum designers and students are all welcome.
